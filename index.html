What is CI/CD?

CI/CD stands for Continuous Integration and Continuous Deployment.

It is a modern method used in software development.

It helps developers automatically build and test their code.

When developers push code to GitHub, automatic systems check the project.

After the checks finish successfully, the application can be deployed automatically.

This makes development faster and more reliable.

My Pipeline

In this project I created a simple CI/CD pipeline.

When I push my code to the main branch on GitHub, GitHub Actions starts a workflow automatically.

The workflow checks that the required files exist.

After the checks are completed, the website is deployed to GitHub Pages.

This means every update to the code automatically updates the website online.
