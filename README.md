## ⚙️ CI/CD Pipeline Explanation
This project uses **GitHub Actions** to automate the deployment process. 
Whenever code is pushed to the `main` branch, the workflow:
1. Checks out the code.
2. Verifies that all required files (`index.html`, `style.css`, `script.js`) exist.
3. Automatically deploys the files to **GitHub Pages**.
